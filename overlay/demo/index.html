How it works

Insertion sort grows a sorted prefix one element at a time. It takes the next element (the key) and shifts larger elements in the sorted prefix one place to the right until it finds where the key belongs, then drops it in.

Each comparison and each shift is one step in the stepper above, so you can stop exactly where something looks off and point at it.
